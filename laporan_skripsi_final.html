SIMULASI VARIASI KE-1

DATA INPUT:

  • Gender: Perempuan (Code: 1.0)
  • Lama: 7 Tahun (Norm: 9.15)
  • URICA: 9 (Norm: 0.44)
  • Penyakit: Perut kembung -> Skor Total: 1.00 (Norm: 0.51)
  • NAPZA: Ekstasi -> Jumlah Zat: 1 (Norm: 0.00)

TARGET ASLI: Sedang

A. ANALISA KNN (Jarak)

Perhitungan Jarak ke Tetangga Terdekat (Peringkat 1):
√ [ (1.0 - 1.0)2 (Gender) + (9.15 - 9.15)2 (Lama) + (0.44 - 0.44)2 (URICA) + ... ]
= 0.0442 (Jarak Euclidean)

Karena jaraknya sangat kecil (0.0442), maka sistem menganggap pasien ini mirip dengan Tetangga 1 yang berstatus Sedang.

B. ANALISA NAIVE BAYES

1. TEOREMA BAYES (Posterior):
P(Kelas|Data) = ( P(Kelas) × P(Data|Kelas) ) / P(Data)

2. LIKELIHOOD (Peluang Fitur):
Karena data berupa angka (Skor Penyakit, URICA, dll), sistem menggunakan rumus Gaussian PDF (Kurva Lonceng):
P(x) = ( 1 / √(2πσ2) ) * e-(x-μ)2 / 2σ2
(Dimana μ=rata-rata dan σ=standar deviasi data latih)
